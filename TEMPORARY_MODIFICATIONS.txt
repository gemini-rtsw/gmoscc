	TEMPORARY MODIFICATIONS
	=======================

The following temporary modifications have been made to the GMOS
Components Controller software:


1) Translation stage modifications for GMOS thermal tests
---------------------------------------------------------
A temporary version of the translation stage software was created in
"/sw3/gmos/experiments/gmos_coldtests" specifically for the GMOS cold tests.
Look for comments containing the string "COLDTEST".

src/devTranslationAss.c  -  Modified so the cross talk and thermal
        corrections are reported but not actually made.

        Also does not use the filtered temperature.

This version to be used only for the cold tests.

cjt - additional changes were made to capfast/translation.sch to output the
calculated offset and temperatures from the assembly record.

These changes will be resolved once the GMOS thermal calibration has been
completed.

cjt (26-03-01) - delivered software has these changes still in place as thermal
model is not complete. The translation assembly has ability to calculate
subsets of the offsets (thermal/x-talk/etc), calculate and output but not
apply, or not calculate etc. This can be selected by the user (record dedicated
to the purpose was added some time ago). This record should NOT be removed
after the thermal model is implemented.

2) Modifications to work around the power status problem
--------------------------------------------------------
The power status signal reported by the GMOS electronics supplies a
voltage that is too low to trigger the XYCOM reliably, resulting in
random changes to that signal. The mask devices are the worst affected,
but other devices have shown this problem as well.  The following
changes have been made to prevent the GMOS software from stopping with
an error every time the signal fluctuates:

pv/gmMask.pv        -  Modified to set UPSB=NO for all mask devices.
pv/gmFilter.pv      -  Modified to set UPSB=NO for all filter devices.
pv/gmGrating.pv     -  Modified to set UPSB=NO for all grating devices.
pv/gmTranslation.pv -  Modified to set UPSB=NO for all translation devices.
pv/gmOiwfs.pv       -  Modified to set UPSB=NO for the base and pickoff devices.

In addition, the initial check on the UPSB field has been commented out in all
these checkout scripts.

test/scripts/cassetteCheckout.scr
test/scripts/cassettePinCheckout.scr
test/scripts/extractorCheckout.scr
test/scripts/gripCheckout.scr
test/scripts/releaseCheckout.scr
test/scripts/tiltACheckout.scr
test/scripts/tiltBCheckout.scr
test/scripts/tiltCCheckout.scr
test/scripts/tiltDCheckout.scr
test/scripts/wheel1Checkout.scr
test/scripts/wheel2Checkout.scr
test/scripts/xaxisCheckout.scr
test/scripts/yaxisCheckout.scr
test/scripts/zaxisCheckout.scr

In addition, the check on the PSTA field has been removed from this script:

test/scripts/wfsCheckout.scr

All the above files will need to be edited when this electronics problem is fixed.


3) Modifications to X and Y axis checkout scripts
-------------------------------------------------
There is currently a bug in the device control record which makes the HSWA
field unreliable when the device has hit one of its soft limits. This field
should not be relied on until the bug has been fixed.

The following checkout scripts:

test/scripts/xaxisCheckout.scr
test/scripts/yaxisCheckout.scr

check that the home switch status is correct at both soft limits. This check
has been commented out in both of the scripts.

To be reinstated when the device record HSWA bug has been fixed.
